# 公共组件

可复用的 Vue 组件，供各页面按需引入。

## 顶层组件

| 文件 | 功能 |
|------|------|
| `AuroraBg.vue` | 极光背景 — 登录页/首页的动态光晕底色 |
| `MouseGlow.vue` | 鼠标发光 — 跟随指针的表面光效，模拟液态玻璃 |
| `HeroBanner.vue` | 首页横幅 — 顶部宣传大图，图片来自收容所信息 |
| `DeveloperCard.vue` | 开发者名片 — 收起时只留头像，点击展开 |
| `LoginPrompt.vue` | 登录提示 — 未登录时的引导弹窗 |
| `NotificationBell.vue` | 通知铃铛 — 右上角图标 + 未读红点，弹窗显示最新 5 条 |
| `ThemeSwitcher.vue` | 主题切换 — 10 套预设主题的切换面板 |

## pet/ — 宠物详情页专用

| 文件 | 功能 |
|------|------|
| `PetImageCarousel.vue` | 图片轮播 — 宠物相册，多图切换 |
| `PetInfoCard.vue` | 信息卡片 — 品种、年龄、性别、健康状况等 |
| `CommentSection.vue` | 评论区 — 评论列表 + 发表 + 嵌套回复 |
| `AdoptFormDialog.vue` | 领养申请弹窗 — 提交领养申请表单 |
