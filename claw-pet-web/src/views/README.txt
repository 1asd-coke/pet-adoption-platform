# 页面视图

所有路由页面组件，按功能模块划分子目录。

## 子目录功能

| 目录 | 功能 |
|------|------|
| `admin/` | 管理后台 — 10 个页面：仪表盘、宠物管理、分类管理、领养管理、领养记录、用户管理、收容所编辑、领养须知管理、小常识管理、故事管理 |
| `adopt/` | 我的领养申请 |
| `auth/` | 登录 / 注册 / 忘记密码 |
| `comment/` | 我的评论页（旧，已重定向至消息中心） |
| `favorite/` | 我的收藏 |
| `guide/` | 领养须知 — 前台展示页 |
| `home/` | 首页 |
| `message/` | 消息中心 — 通知 + 评论 + 回复 |
| `notification/` | 通知列表页（旧，已重定向至消息中心） |
| `pet/` | 宠物列表 + 宠物详情 |
| `profile/` | 个人中心 |
| `story/` | 领养故事 — 故事列表 + 故事编辑器 |
| `tip/` | 小常识 — 常识列表 + 详情页 |
