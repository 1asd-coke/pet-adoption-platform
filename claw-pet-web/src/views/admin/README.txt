# 管理后台页面

面向管理员的后台管理界面，共 10 个页面。

## 文件列表

| 文件 | 功能 |
|------|------|
| `DashboardView.vue` | 仪表盘 — 全局统计概览（宠物数、领养数、用户数等） |
| `PetManage.vue` | 宠物管理 — 宠物列表 CRUD、上下架 |
| `CategoryManage.vue` | 分类管理 — 宠物分类 CRUD |
| `AdoptManage.vue` | 领养管理 — 领养申请审核 |
| `RecordManage.vue` | 领养记录 — 已完成的领养历史 |
| `UserManage.vue` | 用户管理 — 用户列表、角色管理 |
| `ShelterEdit.vue` | 收容所编辑 — 收容所信息修改 |
| `GuideManage.vue` | 领养须知管理 — 领养指南条款 CRUD |
| `TipManage.vue` | 小常识管理 — 宠物养护知识 CRUD |
| `StoryManage.vue` | 故事管理 — 领养故事审核与发布 |
