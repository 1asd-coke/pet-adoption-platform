# API 模块

Axios 实例配置及所有 API 接口封装。基于 `index.js` 中创建的 Axios 实例，统一处理请求拦截、响应拦截和错误处理。

## 文件列表

| 文件 | 功能 |
|------|------|
| `index.js` | Axios 实例配置（baseURL、拦截器、token 注入） |
| `auth.js` | 登录、注册、验证码、密保问题 |
| `pet.js` | 宠物 CRUD |
| `category.js` | 分类管理 |
| `adopt.js` | 领养申请 |
| `comment.js` | 评论 |
| `favorite.js` | 收藏 |
| `notification.js` | 通知 |
| `stats.js` | 统计 |
| `user.js` | 用户管理 |
| `shelter.js` | 收容所信息 |
| `record.js` | 领养记录 |
| `guide.js` | 领养须知 |
| `tip.js` | 小常识 |
| `story.js` | 领养故事 |
