com/clawpet/ — Java 后端源码根包
=================================
包名：com.clawpet
按功能分层：
- common/     — 公共工具（Result、异常处理）
- config/     — Spring Boot 配置类
- controller/ — API 接口控制器
- dto/        — 数据传输对象
- entity/     — 数据库实体类
- mapper/     — MyBatis 数据访问接口
- security/   — JWT 安全认证
- service/    — 业务逻辑接口 + impl/ 实现
